# Alpha123 空投监控 部署指南（中文+英文对照）

> GitHub 网站是英文的，本指南每个步骤都标注了**实际界面上的英文文字**，照着英文找按钮即可。

---

## 第 1 步：注册/登录 GitHub

1. 浏览器打开 https://github.com/
2. 如果没账号：点右上角 **"Sign up"**（注册），按提示用邮箱注册
3. 如果有账号：点右上角 **"Sign in"**（登录）

---

## 第 2 步：创建新仓库

1. 登录后，点右上角你的头像旁边的 **"+"** 号 → 选 **"New repository"**（新建仓库）

   或者直接打开这个链接：https://github.com/new

2. 在页面里填写：
   - **Repository name**（仓库名）：输入 `alpha123-monitor`
   - **Description**（描述，可选）：可填 `airdrop monitor`，也可不填
   - 下方选项：选 **"Public"**（公开，免费无限运行；脚本里没有 Token，安全）
   - **不要勾选** "Add a README file"（不要打勾）
   - 其他保持默认

3. 拉到页面最下方，点绿色的 **"Create repository"**（创建仓库）按钮

---

## 第 3 步：上传文件

进入刚建好的空仓库后：

1. 找到并点击 **"uploading an existing file"**（上传已有文件）这个蓝色链接

   > 如果没看到这个链接，地址栏直接访问：`https://github.com/你的用户名/alpha123-monitor/upload/main`

2. 把之前下载的 `alpha123-monitor-github.zip` **解压**后，把里面的所有文件和文件夹**拖拽**到网页上的虚线框里
   - 注意：要包含 `.github` 文件夹（这是隐藏文件夹，但拖进去能上传）
   - 如果拖拽 `.github` 不成功，见下方"备用方法"

3. 等待上传完成（文件名会逐个显示出来）

4. 拉到页面下方，在 **"Commit changes"**（提交更改）框里：
   - 上面那个输入框可改可不改（默认是 "Upload files"）
   - 直接点绿色的 **"Commit changes"** 按钮

### 备用方法（如果 .github 文件夹拖不上去）

`.github` 文件夹必须上传，否则监控不会运行。如果拖拽失败，改用以下方法：

1. 先在仓库页面点 **"Add file"** → **"Create new file"**（新建文件）
2. 在文件名输入框里输入：`.github/workflows/airdrop-check.yml`
   - 输入 `.github/` 后会自动变成文件夹
   - 再输入 `workflows/` 又变成子文件夹
   - 最后输入文件名
3. 把 `airdrop-check.yml` 的内容**复制粘贴**到大输入框里
4. 点下方绿色 **"Commit new file"** 按钮
5. 重复以上步骤，再创建 `.github/workflows/heartbeat.yml`
6. 再创建 `src/airdrop_monitor.py`（方法相同，文件名输入 `src/airdrop_monitor.py`）

---

## 第 4 步：配置 Token（关键步骤）

1. 进入你的仓库页面，点上方标签栏的 **"Settings"**（设置，齿轮图标）

   > 地址栏访问也行：`https://github.com/你的用户名/alpha123-monitor/settings`

2. 左侧菜单找到 **"Secrets and variables"**（密钥和变量），点它展开 → 点 **"Actions"**

3. 点绿色按钮 **"New repository secret"**（新建仓库密钥）

4. 在弹出的表单里：
   - **Name**（名称）：输入 `XTUIS_TOKEN`（注意全大写，有下划线）
   - **Secret**（密钥值）：粘贴你的虾推啥 Token
   - 点绿色 **"Add secret"**（添加密钥）按钮

5. 配置完成后，列表里会出现一条 `XTUIS_TOKEN`（值会显示为 `Added ... ago`，看不到具体内容是正常的）

## 第 5 步：手动测试一次

1. 进入你的仓库页面，点上方标签栏的 **"Actions"**（操作，三角形图标）

2. 左侧会看到两个 workflow：
   - **"Alpha123 空投监控"**
   - **"Alpha123 心跳检查"**

3. 先测空投监控：
   - 点左侧 **"Alpha123 空投监控"**
   - 右侧会出现一个黄色横条提示，点里面的 **"I understand my workflows, go ahead and enable them"**（我了解我的工作流，继续启用）蓝色按钮
   - 然后右侧出现一个灰色按钮 **"Run workflow"**（运行工作流），点它
   - 弹出小框，保持默认（Branch 选 `main`），点绿色的 **"Run workflow"** 按钮

4. 等约 30 秒到 1 分钟，微信「虾推啥」公众号应该收到一条卡片显示 `*0` 的通知（监控启动通知）

5. 再测心跳：
   - 点左侧 **"Alpha123 心跳检查"**
   - 同样点 **"Run workflow"** → 绿色 **"Run workflow"**
   - 等一会儿，微信收到卡片 `^_^ 1`（运行正常）

收到这两条通知，就说明部署完全成功！之后会按时间表自动运行。

## 第 6 步：查看运行情况（日常用）

部署成功后，您平时不用管。如果想看运行记录：

1. 进入仓库 → 点 **"Actions"** 标签
2. 左侧选某个 workflow
3. 中间会列出每次运行记录（绿色 ✓ = 成功，红色 ✗ = 失败）
4. 点某次运行 → 点 **"check"** 或 **"heartbeat"** → 展开 → 点 **"Run airdrop_monitor"** 或 **"Run heartbeat"** 能看到详细日志

## 常见问题

**Q: 上传文件时找不到 "uploading an existing file" 链接？**
A: 确认你已经在**自己的仓库**页面（地址含你的用户名和仓库名），不是在 GitHub 首页。空仓库才会显示这个链接。

**Q: Actions 标签里看不到任何 workflow？**
A: 说明 `.github/workflows/` 文件夹没上传成功，请用第 3 步的"备用方法"手动创建。

**Q: 运行后报错怎么办？**
A: 点进那次失败的运行 → 展开日志看红色报错信息，把错误内容发给我，我帮你判断。

**Q: 想暂停监控？**
A: Actions → 选 workflow → 右上角 **"..."** → **"Disable workflow"**

**Q: 免费额度够吗？**
A: 公开仓库无限免费。所以一定要选 Public，不要选 Private。
